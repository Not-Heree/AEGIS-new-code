2. Backend Architecture (The "Sniper" Engine)
Logic Pipeline (scanner.py)
Run this in a background thread using Python threading.

Discovery: subfinder -d <domain> -silent. (Count results for Card 1).
Ports: naabu -top-ports 100. (Count results for Card 2).
Tech: httpx -tech-detect. (Used for Nuclei filtering).
Vulns: nuclei -severity critical,high. (Count results for Card 3).
Enrichment: Match findings to remediation.py for fix advice.
3. Code Quality & Standards (STRICT ENFORCEMENT)
You must adhere to PEP 8 and Professional Engineering practices. The code must be "university submission ready."

Rich Inline Comments:
Do not just comment what the code does (e.g., # Connect to DB).
Comment why it does it (e.g., # Use a timeout of 2000ms to prevent hanging on dead hosts).
Comment every major step in the scanning pipeline.
Type Hinting: All functions must use type hints.
Example: def run_scan(domain: str, scan_id: str) -> Dict[str, Any]:
Docstrings: Every function must have a docstring explaining arguments, return values, and potential exceptions.
Modular Separation:
app.py: Handles Routes only.
scanner.py: Handles Logic only.
db.py: Handles Data Persistence only.
Variable Naming: Use descriptive snake_case.
Bad: res = tools.run(d)
Good: scan_results = tool_manager.execute_subfinder(target_domain)
Input Sanitization: In app.py, validate that the domain input is clean before passing it to subprocess.
Error Handling: Wrap all external tool executions in try/except blocks to prevent crashes.
